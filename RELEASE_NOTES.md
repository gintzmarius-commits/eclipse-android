**Eclipse pour Android 2.0.1** : le scanner de QR code s'ouvre.

- Correction : en 2.0.0, le bouton « Scanner le QR code » affichait une erreur (« getClass() on a null object reference ») au lieu d'ouvrir le scanner.
- Si le scanner ne s'ouvre pas, le message donne maintenant un détail technique.

Rappel 2.0 : sur le PC, ouvre Eclipse et clique « Connecter un appareil ». Dans Eclipse sur le téléphone, touche « Scanner le QR code » et vise l'écran : c'est connecté, sans rien taper. Il faut Eclipse 2.0 sur le PC et Android 6 ou plus récent.

Installe **Eclipse.apk** ci-dessous, par-dessus la version précédente : tes PC restent connectés.
