Android avec Éclat iPhone, même Wi-Fi

ÉclatLecteur et gestionnaire de fichiers

Envoyer par NFC. Ouvre une photo et glisse-la vers le haut, ou appuie longuement sur un fichier → « Partager via NFC ». Puis mets les deux téléphones dos contre dos.

Sur Android, l'autre téléphone doit avoir Éclat (même fermé) : une bulle apparaît en haut de l'écran, il suffit de toucher « Accepter ».

Sur iPhone (XS ou plus récent, écran allumé), sur le même Wi-Fi : une notification s'affiche, elle ouvre la page de téléchargement dans Safari.

Le fichier passe par le Wi-Fi (le NFC sert à se trouver). Sans Wi-Fi, le téléphone qui envoie crée un petit réseau Wi-Fi pour l'autre téléphone Android.
